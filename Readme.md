# Teacher AI Backend

## Description
Node.js + Express backend for collecting teacher problems and generating AI-based teaching strategies.

## Features
- REST APIs using Express
- AI logic service for solution generation
- In-memory data store (DB-ready)
- Health check API
- Analytics-ready backend

## APIs
- GET / → Backend status
- GET /health → Health check
- POST /api/teacher/problem → Submit teacher problem
- GET /api/teacher/stats → Analytics

## Tech Stack
- Node.js
- Express
- JavaScript
- Postman (testing)

## Future Scope
- MongoDB / Supabase integration
- Authentication
- Admin dashboard
